# 学习材料入口

当 Word 的内容不是普通报告，而是讲义、培训手册、教程、知识库文章或自学材料时，先读 `learning-material-design`。这里只保留办公交付时最常用的检查卡。

## 先判断

满足以下任一条，按学习材料处理：

- 读者需要在读完后解释、比较、计算、判断或完成一个操作。
- 材料包含概念教学、步骤训练、案例诊断或复习。
- 用户说“看完记不住”“太难”“不会做题”“帮我整理成课程/讲义/培训材料”。

如果只是普通汇报、会议纪要、方案或正式文件，仍按 `wf-office` 的普通文档路径走。

## 八项硬检查

1. **学习结果**：用可观察动词写清读完后会做什么。
2. **先备知识**：关键术语、符号和前置操作在需要之前出现。
3. **切片**：一节一个主要判断或任务；长节拆开。
4. **例子与反例**：抽象规则至少配一个正例，容易混淆时配反例或边界。
5. **练习**：关键概念后有闭卷提取题，不是只放“思考一下”。
6. **反馈**：答案解释为什么，并指出常见错误和下一次检查点。
7. **复习与迁移**：有间隔复现和换条件任务，不只重复原文。
8. **版式**：练习有作答空间，答案不提前泄露；图、表、注释贴近对应文字；渲染可读。

## 交付分工

| 事情 | 负责 |
| --- | --- |
| 学什么、何时学、进度、错题记录 | `wf-study` |
| 学习目标、内容精加工、例子/练习/反馈、教学性排版 | `learning-material-design` |
| Word 文件、图表插入、目录/页码、渲染验收 | `wf-office` |
| 语言自然度 | `oil-tone` |
| 数据图表 | `create-viz` / `data-visualization` |

## 常见反模式

- 标题很多，但读者不知道要会什么。
- 一节塞多个新概念，只有定义没有例子。
- 练习答案就在题目下方。
- 复习只是“再看一遍”。
- 为了好看加大量图标、边框和颜色，反而增加无关负荷。
- 把“学习风格”当作分班或选媒材的科学依据。

完整原则和审查清单在 `learning-material-design` 的 `references/` 中，不在本工作流重复。
