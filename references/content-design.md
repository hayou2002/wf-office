# 办公文档内容设计

这份规则解决“读者能不能顺着读懂、记住并行动”，不是只把页面弄漂亮。先定信息，再排版。

如果目标是学习、培训或掌握一项能力，不要只停在这份通用规则；先走 `learning-material-design` 的学习结果、练习、反馈与迁移流程。

## 1. 先写文档契约

正式动笔前，用一页以内的表回答：

```text
读者：谁在什么场景读，已经知道什么
目的：读完后要做一个什么决定、动作或产出
结论：全文最重要的一个判断
材料：哪些是事实、来源、日期；哪些是假设或待核实
结构：章节 / 页 / 表的主线
交付：DOCX / PDF / 模板 / 页数 / 尺寸 / 语言
验收：用户怎样判断这份文件可以发
```

只问资料中查不到、且会改变方向的问题。一次集中 1–3 个，并给推荐默认值。

## 2. 结构

- 全文只服务一个中心问题；中心问题写不出来，先不要做版式。
- 每一节按“结论 → 证据 → 限制或行动”组织；不要把背景写成正文主体。
- 每一段只承担一个主要意思，通常 3–5 句。段落之间要有读者看得出的关系。
- 标题写对象、判断或任务，不写空泛的“概述”“相关分析”。
- 目录层级连续，不跳级；Word 长文不超过 3–4 级标题。

可用的结构：

| 结构 | 适用 |
| --- | --- |
| 结论 → 依据 → 行动 | 汇报、建议、决策材料 |
| 问题 → 原因 → 方案 → 风险 | 方案、复盘、故障说明 |
| 时间线 / 阶段 | 项目进展、过程说明 |
| 现状 → 目标 → 差距 → 计划 | 规划、工作要点 |
| 概念 → 例子 → 练习 → 总结 | 培训、学习材料 |

## 3. 信息呈现

普通办公文档只保留以下阅读规则；学习材料的认知负荷、示范和练习规则统一由 `learning-material-design` 负责：

- 删掉与目标无关的装饰、重复说法和“为了显得完整”的章节。
- 新术语第一次出现时解释；不要突然引入未定义概念。
- 图文放在一起，图上直接标注关键点；不要只在正文里解释图。
- 不要在同一屏同时放完整讲稿和大量说明文字；投影页只保留听众需要看的判断。
- 需要读者行动时，用小结或例子确认行动条件，不把办公报告机械改成练习册。

## 4. 例子与证据

- 抽象规则至少配一个正例；容易误解时再配反例或边界例。
- 对比时只改变一个关键维度，避免同时换多个条件。
- 例子必须与读者要做的判断或行动相关；事实、推断和建议分开。
- 学习、练习和复习需求转 `learning-material-design`，不在这里维护另一套教学规则。

## 5. 图表与表格

| 要表达的关系 | 首选 | 说明 |
| --- | --- | --- |
| 时间趋势 | 折线图 | 比较多个系列时保持同一尺度 |
| 类别比较 | 条形图 | 类别多时用横向条形 |
| 排名 | 横向条形图 | 按值排序，不按字母排序 |
| 部分与整体 | 堆叠条形图 | 少于 6 类才考虑饼图 |
| 分布 | 直方图 / 箱线图 | 先说明样本量和分组 |
| 相关 | 散点图 | 不把相关直接写成因果 |
| 精确查询 | 表格 | 带单位、同列同精度 |

硬规则：

- 柱状图从 0 开始；不截断柱轴。
- 不用 3D 图、装饰性渐变和没有信息量的网格。
- 颜色不能作为唯一区分方式；同时使用线型、标记或直接标签。
- 标题写结论，轴标题带单位，数据来源和日期放在图下或脚注。
- 关键图保留底层数据表或可追溯数据文件；不编造数字。

## 6. 中文排版与阅读节奏

- 一般打印正文 10.5–12 pt，行高 1.5–1.75；屏幕正文按平台规范放大。
- 中文正文行宽以 28–40 字左右为宜；40 字是 WCAG AAA 的上限，不是最佳值。
- 开头 3–5 行给结论或路线图；每页/每节至少一个扫描锚点：小标题、列表、粗体关键词、图或检查题。
- 中文句使用中文标点；英文缩写、代码、版本号和小数使用半角；中文与英文/数字之间留细间隙。
- 标题、正文、图表和页脚保持清楚的层级；不要用多个字体和字号堆出“设计感”。
- 正文对比度至少 4.5:1，大字至少 3:1；颜色不是唯一信息载体。

注意：WCAG 是 Web 标准，这里只借用可读性和无障碍判据，不宣称 Office 文件“符合 WCAG”。GB/T 15834 只规范标点；正式公文另行遵循 GB/T 9704-2012。

## 7. 写完后逐项自检

1. 只读标题和各段首句，能否复述全文主线？
2. 每个数字、日期、机构名、引用和结论是否有来源或明确标为待核实？
3. 每一节是否有存在的理由，删除后会不会影响判断？
4. 图表是否回答了正文提出的问题，单位和来源是否齐全？
5. 读者能否在不打开外部链接的情况下理解主要内容？
6. 长文是否有目录、页码、题注和必要的交叉引用？
7. 打印或渲染后是否仍有孤行标题、溢出、遮挡、乱码或图表断裂？
